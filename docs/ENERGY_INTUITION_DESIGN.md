# 能量直觉层（Energy Intuition Layer）技术方案 v0.2

> v0.2 修订说明：根据评审意见，撤回 v0.1 中三处未经证明的断言
> （「局部最低点即好方案」「−E(z*) 即置信度」「离散无法泛化」），
> 把验收标准从「能量面形状」改为「同预算下的实际任务收益」。

## 0. 结论先行（修订版）

- **待检验的核心命题**（不再作为前提）：
  在固定计算预算下，K 步能量下降 + 解码，其任务成功率显著高于直接前向预测。
  此命题证伪则整个路线终止。
- 能量定义在连续潜空间，但连续性只是**求解手段**，不是正确性保证。
- 置信度是一组**待校准的特征**，须用独立验证集的真实成功标签拟合，
  并与温度缩放基线对比。
- Stage-1 只回答两个问题：① 下降是否带来真实收益；② 能否识别自身易错情形。

## 2. 对 v0.1 的修订（逐条）

### 2.1 撤回「灵光一闪 = 局部最低点」作为结论
局部最低点仅表示在**学到的**能量函数下邻域无更优方向，可能对应错误答案、
解码无效区或训练漏洞。该表述降级为直观类比。
理论基础参考 SPEN（arXiv:1511.06350）与端到端 SPEN（arXiv:1703.05667）：
用学习到的能量函数经梯度优化产生结构化预测，已有可借鉴的成熟做法。
本项目差异化重点放在：**短步求解、可靠分流、执行反馈适应**。

### 2.2 置信度重写
撤回 `τ = σ(w·(−E(z*)) + ...)`。原因：排序损失不固定能量零点，
`E'(h,z) = E(h,z) + c(h)` 不改变排序、梯度与求解结果，却任意改变 `−E(z*)`，
因此谷深不具备可信度语义。

「谷越陡越可靠」同样无保证：模型可以稳定地错；潜空间坐标缩放即可改变曲率
而语义不变。v0.1 中「谷要宽」与「谷要陡」的矛盾一并作废。

修订为：置信度 = 一组特征经**后验校准**得到的概率。

候选特征（全部视为待检验，不预设优劣）：
- 相对能量差 `E(z*_2) − E(z*_1)`（差值不受 `c(h)` 影响，可用）
- 方向曲率，改用**对称差分**（避免未收敛时混入一阶项）：
  `[E(z+δv) − 2E(z) + E(z−δv)] / δ²`
- 多起点解码结果的一致性
- 约束违反量（由独立判定器给出）
- 下降轨迹的能量下降幅度与是否收敛

校准方法：独立验证集 + 真实成功标签，逻辑回归 / isotonic；
**必须与温度缩放基线对比**（arXiv:1706.04599），不预设优于 softmax。
评价用 ECE、可靠性曲线、以及「高置信区间的实际错误率」。

### 2.3 训练目标：补上「能排序 ≠ 能到达」的缺口
`L_rank` 只约束训练样本处的相对能量，样本之间仍可能存在错误吸引子；
平滑正则限制变化率，但不保证梯度方向有用，更不保证 K 步到达。

修订为**展开式训练**（unrolled optimization）：
- 训练时展开推理时实际使用的 K 步下降，对**第 K 步解码后的任务质量**直接求导监督
  （对梯度推理过程反向传播，参考端到端 SPEN）
- **难负样本挖掘**：把求解器自己找到的「低能但错误」的 z* 加入负样本池，
  每轮更新，专门填补错误吸引子
- `L_rank` 与平滑正则保留为辅助项，不再是主目标

诚实声明：**「多起点 + K 步下降」仍属优化搜索，不是一次前向。**
「一次前向出直觉」只有在 Stage-3 蒸馏成 amortized 求解器后才成立。

### 2.4 潜空间：可解码性需实测，不靠 AE 重构背书
AE 重构良好只说明已有样本邻域可还原；KL 或 VQ 都不保证
**任意优化轨迹上的点**可解码为有效方案（VQ 还有量化边界，不是光滑性保证）。

需要警惕的失效模式：能量持续下降但解码结果长期不变，
越过某个边界后突然跳为无效方案。

修订：
- **监控整条轨迹每一步的解码质量**，而非只看终点能量
- Stage-1 改用**可自动验证的结构化方案**（有独立判定器），文本 AE 推迟到 Stage-2
- 删除 v0.1 中「离散无法泛化」与「Maze 4/10 由离散候选导致」的论断：
  离散对象可共享表示、表达相似性；单一评测结果不足以支持该因果归因。
  选择连续的真实理由是**可微、便于短步求解**，仅此而已。

### 2.5 在线塑形：降级为独立验证项
原式 `ΔE = a·exp(−||z−z_fail||²/2σ²)` 有两个问题：

1. **缺情境**：同一方案在状态 A 失败、状态 B 可能正确。改为情境化核：
   `ΔE(h,z) = a · K_h(h, h_fail) · K_z(z, z_fail)`
2. **高斯隆起在中心梯度为零**：若失败点本就是驻点，抬高能量不保证能离开，
   需配合扰动、重新初始化或显式排斥项。

另需区分**方案错误**与**工具偶发失败**，否则一次执行故障会错误惩罚好方案。
在线塑形不再宣称「无需重训即可学会避坑」，作为单独实验验证。

### 2.6 与现有 FreeEnergyLM 的取舍
现有 `fe_llm/energy_lm/models/free_energy_lm.py` 使用凸二次能量 + 受限步长，
**具备明确的下降保证**。换成通用非凸能量网络会失去该保证，因此必须补上：
- 步长控制（line search 或自适应 η）
- 每步下降检查（能量未下降则回退/减半步长）
- 显式停止条件（能量变化阈值 + 最大步数）
- 与凸二次版本作为基线之一直接对比

## 3. Stage-1 实验设计（重写）

**唯一目标**：在相同计算预算下，回答
① K 步能量下降能否比直接前向预测更准确；② 能否识别自身易错情形。

| 项目 | 设定 |
|---|---|
| 任务 | 小型约束规划，**有独立自动判定器**；训练/测试按**约束组合**划分（非随机划分） |
| 潜空间 | 先 16–32 维，便于排查；不急于上高维 |
| 对照组 | ① 直接前向预测 ② 零步（z₀ 直接解码） ③ K=5 步下降 ④ **同计算预算的采样择优** ⑤ 现有凸二次 FreeEnergyLM |
| 成功指标 | 解码后任务成功率、约束满足率、实际 wall-clock 耗时 |
| 分流指标 | 高置信子集的错误率、快路覆盖率（能吃下多少比例的任务） |
| 校准指标 | ECE、可靠性曲线；与温度缩放基线对比 |
| 稳健性 | ≥5 个随机种子、未见约束组合、难度递增曲线 |

**预算对齐规则**：多起点/多步实验必须与对照组**固定总前向次数**，
否则提升可能只来自多花算力。

**关于 70% 与 Spearman**：v0.1 的绝对阈值作废。
成功率必须相对基线判断（要求：显著优于「同预算采样择优」这一最强基线）；
Spearman 高不代表校准好，改用 ECE 与高置信错误率。

**轨迹监控**（每步记录）：能量值、解码结果、约束违反量、是否已收敛。
用于诊断「能量降但解码不变」与「越界突变」两种失效。

**消融**：去展开式训练（只用 L_rank）、去难负样本挖掘、去平滑正则、
单边差分 vs 对称差分曲率。

## 4. 阶段门禁

- **Gate-1**：Stage-1 中 K 步下降在同预算下**显著优于**直接预测与采样择优，
  且高置信子集错误率明显低于整体。不达标 → 终止或回到理论修订，不进 Stage-2。
- **Gate-2**：结构化方案跑通后，才引入文本潜空间与 AE。
- **Gate-3**：前两关通过，才做在线塑形与 Qwen3-0.6B 接入（届时评估 GPU 需求）。

## 5. 风险与对策（更新）

| 风险 | 对策 |
|---|---|
| 低能但错误的吸引子 | 展开式训练 + 难负样本挖掘，把求解器自己的错误当负样本 |
| 置信度不可靠 | 后验校准 + 温度缩放基线对比 + 高置信错误率作为一等指标 |
| 轨迹上解码失效 | 全轨迹解码质量监控；Stage-1 用可自动验证的结构化方案 |
| 失去凸能量的下降保证 | 步长控制 + 每步下降检查 + 显式停止条件 |
| 收益仅来自多花算力 | 所有对照固定总前向次数 |
| 在线塑形误伤好方案 | 情境化核 + 区分方案错误与工具偶发失败 + 独立验证 |
