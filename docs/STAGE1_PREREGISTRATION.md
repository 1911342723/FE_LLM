# Stage-1 预注册协议（PREREGISTRATION）— 三着色能量直觉实验

> 本文件在任何实验运行**之前**冻结。运行后如需修改，必须以追加「协议修订记录」的
> 方式留痕，不得静默改写。

## 1. 任务定义

固定三色图着色（3-coloring, 固定 K=3）。

| 项目 | 决定 |
|---|---|
| 输入 | 16 节点无向图（邻接矩阵） |
| 输出 | 每节点一个颜色编号 ∈ {0,1,2} |
| 判对条件 | 所有节点颜色合法，且每条边两端点颜色不同 |
| 主指标 | **整图完全合法的比例**（不得用平均边满足率代替） |
| 数据生成 | 先生成隐藏三色分组，只在不同组间连边，保证有解 |
| 防泄漏 | 隐藏分组不输入模型；随机打乱节点编号；跨集合排除同构重复图 |
| 规模 | 训练 5,000 / 验证 1,000 / 封存测试 1,000 |
| 泛化测试 | 另设边密度变化测试集，单独报告 |

**任何合法三着色均算正确**，不要求复现生成时的隐藏着色。
若训练使用着色标签，必须对颜色编号的 3! = 6 种置换做等价处理
（取最小置换损失或规范化标签），避免把等价答案判为错误。

范围限定：本阶段只研究**有解问题上的可行方案生成**。
无解识别与最少颜色数优化不在本阶段，结论仅限上述生成分布。

## 2. Gate-1 统计协议（事前锁定）

**主比较**：五步能量下降模型 vs 直接前向预测基线。
零步消融、同预算随机采样择优为**辅助比较**，不得事后替换主比较。

| 项目 | 预注册规则 |
|---|---|
| 训练种子 | 固定 `11, 23, 37, 51, 71`，全部报告 |
| 配对方式 | 同种子下两法共用相同数据划分、数据顺序、测试图；模型初始化随机源独立管理 |
| 推理方式 | 主实验固定**单起点、五步**；不按测试结果挑起点 |
| 配对观测 | 每种子一个成功率差 Δᵢ，统计样本量 n = 5 |
| 主检验 | 双侧配对 t 检验，α = 0.05 |
| 区间估计 | 对 5 个配对差值做种子级 percentile bootstrap，10,000 次，双侧 95% CI，重采样种子固定为 20260920 |
| 实际收益门槛 | 平均成功率提升 ≥ **5 个百分点** |
| **通过条件** | 三项**同时**满足：均值提升 ≥5pp、p < 0.05、bootstrap 95% CI 下界 > 0 |

配对 t 检验与配对 bootstrap 来自同一批数据，**不构成两份独立证据**，
仅作为同一结论的两种呈现。

**预算封存**：两法使用相同训练数据、相同调参次数、预先规定的计算上限；
报告实际训练与推理 wall-clock 耗时。
若成功率通过但耗时显著增加，只能认定**有效性改善**，不得声称效率改善。

## 3. 执行期硬边界

1. **测试集只在配置冻结后开启一次。** 超参与 checkpoint 选择只看验证集。
2. **不删除不利种子，不边看显著性边追加种子。** 数值发散属于实验结果；
   仅基础设施故障可按原配置重跑，并在日志留记录。
3. **未通过记为「证据不足」**，不表述为「已证伪」也不表述为「趋势向好」。
   5 个种子无法检验 t 检验的分布假设，bootstrap 也不能补足独立重复数量；
   结论仅限固定数据集上的训练随机性（参考 arXiv:1806.08295）。

## 4. 与置信度门槛的分离

Gate-1 **只裁决求解收益**。
置信度校准（ECE、可靠性曲线、高置信子集错误率、与温度缩放基线对比）
另设独立门槛 Gate-1b，事后单独预注册，
避免把「解得更好」与「知道自己何时会错」混为同一结论。
